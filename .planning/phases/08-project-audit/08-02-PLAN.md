**Section 1: Workflow Gaps (AUD-02)**

Per D-13, analyze ALL workflow stages: structural validation, AI review (Haiku/Sonnet routing), report generation, Notion publishing, batch feedback routing. For each stage, evaluate:

1. **Missing steps**: Is there a gap between what the workflow promises and what it delivers? Examples to investigate:
   - Does the structural validator catch all the recurring errors listed in CLAUDE.md `## Recurring errors to watch for`? For each recurring error type, check if `structural_validator.py` has a corresponding check.
   - Is there a gap between Step 7 (feedback) writing to corrections_log.json and those corrections actually being used in the next review run? Trace the data flow: corrections_log.json → rules_summary.json → AI review context injection.
   - After Notion publishing, is there any mechanism to track which reports have been reviewed by the team? Or does the workflow end at "published"?

2. **Brittle steps** (per D-14, tag as "brittle" alongside priority label):
   - CSV parsing assumptions (France at position 0 — already known as QUA-01, but are there others?)
   - Hardcoded paths or format assumptions that break with different CSV structures
   - Any step that silently succeeds but produces wrong output (e.g., missing config file causes empty results instead of error)

3. **Unscalable steps**:
   - What happens when notification count grows from current ~10 to 50+?
   - What happens when language count changes?
   - Per D-15, manual confirmation in batch feedback is intentional — flag as a workflow note (future improvement when confidence grows), NOT a gap requiring immediate fix.

**Section 2: Scope Gaps (AUD-03)**

Compare the Phase 1 vision (from PROJECT.md active requirements) against what is actually implemented. For each planned capability:
- **Never-built**: Planned but zero implementation exists (e.g., README — HND-01)
- **Partially-built**: Some code exists but is incomplete or not wired (e.g., generate_pdf.py exists but has no CLI args — HND-03)
- **Built-but-stale**: Was implemented but the project moved on and it is no longer relevant (e.g., PDF output if confirmed dead)

Cross-reference against: HND-01 (README), HND-02 (requirements.txt), HND-03 (PDF CLI), QUA-01 (France ref search), QUA-02 (Unicode emoji), QUA-03 (corrections backup).

Each finding gets: `[#N]` (continuing from Plan 01's numbering), gap type, affected stage/capability, evidence, severity suggestion.
