## Integration Gaps

### FINDING-01 — Critical: `--type` flag crashes structural_validator.py at Step 2

**Severity:** Critical (blocks every review run)
**Location:** [`.claude/commands/review-translations.md:63`](.claude/commands/review-translations.md)
**Introduced:** Present in skill file; missed by Phase 7 verifier (which only grep-verified `--summary` was added, not that the full command was valid)

**Problem:** The Step 2 bash command is:
```
python3 scripts/structural_validator.py --input [CSV_PATH] --type [per-notification|full-database] --config-dir config/ --output reports/structural_results.json --summary
```
`scripts/structural_validator.py` defines only `--input`, `--output`, `--config-dir`, `--pretty`, `--summary` in argparse. The `--type` argument is not defined. `parser.parse_args()` (strict mode) rejects unrecognized arguments and exits with code 2 before `--output` or `--summary` are processed.

**Effect:** `structural_results.json` is never written. Step 2 fails. Every review run is broken.

**Fix:** Remove `--type [per-notification|full-database]` from line 63 of `review-translations.md`. The script already handles both CSV formats without this flag.
